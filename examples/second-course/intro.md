# A second course with its own progress

**Time:** about 2 minutes. **Cost:** none. This is a harmless navigation and
progress demonstration, not an actual exam assessment. It needs no runtime,
notebook, cloud account, network access, or package installation.

## Try reasoning about separate courses

This course has a different course ID and unit ID from Foundations. Both can use
display number **01** because that number is a label, not their identity. This
lesson belongs to the second course; its progress should not complete a
Foundations activity.

1. With a compatible Cert Learner build installed, use **Learning: Add Course**
   to select this folder's [course.json](course.json). Add Foundations separately
   if you want to compare them.
2. Select each course in **Learning** and notice the different titles and lessons.
3. Before marking this introduction complete, predict whether either Foundations
   activity should change. The answer is **no**: they are separate course records.
4. Optionally use **Mark complete**, then inspect both courses' progress in the UI.
   This is manual, self-reported progress, not verified competence.

## Repeat safely

**Zero auto-run:** adding, opening, navigating, completing, or resetting this
course does not execute code. No check is declared here. Use the Learning UI's
**Reset progress** control only after reviewing which course or unit it affects.
Never inspect or edit hidden extension storage to change progress.

# Foundations quiz

These questions support a harmless local demonstration, **not an actual exam
assessment**. Answer before reading the key. Nothing runs automatically.

## Questions

1. Two boxes contain two pencils each. How many pencils are there altogether?
2. Remove one pencil from that total. How many remain?
3. Does choosing **Mark complete** prove that you understood the lesson?
4. If the fixed arithmetic check passes, does that prove your answers are correct?
5. Should adding this course or moving to the next activity execute its check?

## Answer key

1. **Four.** Two groups of two give `2 + 2 = 4`.
2. **Three.** Removing one from four leaves `4 - 1 = 3`.
3. **No.** Manual completion is a self-reported learning record.
4. **No.** The script checks its own arithmetic, not your answers. A pass is limited
   evidence about that local check, not understanding, cloud skills, or exam readiness.
5. **No.** Zero auto-run: execution requires your explicit decision and approval.

## Lesson exercise explanation

One possible explanation is: "I count two pencils in the first box, then two more,
so there are four in total." A script that always evaluates the same expression
cannot determine whether you can explain it. Use your reasoning and these answers
to review learning; use the Learning UI to manage progress, not hidden storage.
